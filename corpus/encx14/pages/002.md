## Conventions used in this manual

Numbers. Hexadecimal values carry a 0x prefix (0x4C). Binary values carry a
0b prefix (0b011). All other numbers are decimal.

Bit fields. A field is written NAME[msb:lsb]. FILT[2:0] is the three-bit
field FILT that occupies bits 2, 1 and 0 of its register. Bit 0 is the least
significant bit.

Register access types.

  R     read only
  W     write only (reads return 0)
  RW    read and write
  RC    read, cleared by the read (sticky flag)
  OTP   one-time programmable; the value survives power cycles

Angles. One LSB of the angle output is 360°/16384 = 0.02197° = 383.5 µrad
(2 x pi / 16384 rad). "Code" means the unsigned 14-bit output value in the
range 0 to 16383.

Noise. Noise figures are root-mean-square (RMS) values measured over 10,000
consecutive reads with the magnet at rest, unless stated otherwise.

Typical and limit values. "Typ" values are at 25 °C and VDD = 3.3 V. "Min"
and "Max" values hold over the full recommended operating range (page 10).

Notes. Paragraphs headed "Important" describe behaviour that has caused
field problems. Read them before writing firmware.
