# 27 Accuracy and linearity

## 27.1 Definitions

  INL     Integral non-linearity: the largest deviation of the output from a
          straight line through the full revolution, after removing offset.
  Drift   Change of the output at a fixed angle over temperature.
  Noise   Random variation of consecutive reads at a fixed angle (page 26).

## 27.2 Specifications

Table 27-1. Accuracy (reference magnet, 1.5 mm air gap, perfect alignment).

  Parameter                         Typ       Max       Unit
  INL, 25 °C                        0.10      0.25      °
  INL, -40 to 125 °C                0.15      0.40      °
  Zero drift, -40 to 125 °C         0.05      0.12      °
  Hysteresis (HYST = 0)             0         0         LSB
  Output noise, FILT = 0            12.0      14.0      LSB RMS
  Output noise, FILT = 3            3.10      3.6       LSB RMS
  Output noise, FILT = 7            0.75      0.9       LSB RMS

## 27.3 Notes

1. INL includes the CORDIC error and the effect of magnet inhomogeneity. It
   excludes alignment errors (page 21).
2. Noise values are at 60 mT. See page 26 for other field values.
3. Max noise values are the 3-sigma production limits.

## 27.4 Improving accuracy

  - Calibrate the INL with a look-up table in the host.
  - Use FILT to reduce noise, at the cost of phase lag (page 12).
  - Average several reads in the host only if the host reads faster than
    the ANGLE update rate; otherwise averaging repeated values does nothing
    (page 25).
