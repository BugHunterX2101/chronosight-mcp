# 33 STATUS register

## 33.1 STATUS (0x0B, RC)

Table 33-1. STATUS bit fields.

  Bits   Field   Type   Description
  7:5    -       R      Reserved, read as 0
  4      OVF     RC     CORDIC overflow (field too weak to compute an angle)
  3      MD      R      Magnet detected (field between 20 mT and 120 mT)
  2      MAGH    R      Field too strong (> 90 mT)
  1      MAGL    R      Field too weak (< 30 mT)
  0      RST     RC     A reset has occurred since STATUS was last read

## 33.2 The RST flag is sticky

RST is set by every reset: power-on, brown-out, watchdog and soft reset
(page 11). It stays set until the host reads STATUS. Reading STATUS clears
RST and OVF. The value returned by that read still shows RST = 1; the flag
is cleared after the read completes.

This means:

  - The host sees RST = 1 exactly once per reset (or once for several resets
    that happen between two reads).
  - The host must act on RST in the same control step in which it reads it.
    The next read returns RST = 0 even though the configuration is still
    lost.
  - RST = 1 means CONF2 is 0x00 again: FILT is off, DIR = 0, HYST = 0,
    WD = 0 (errata E-3, page 58).

## 33.3 Reading STATUS together with the angle

The recommended way to read STATUS is the 3-byte burst read starting at
0x0B (page 40). It returns STATUS, ANGLE_H and ANGLE_L in one transaction,
so the host checks RST on every control step at no extra cost.

## 33.4 MAGL, MAGH and MD

These flags reflect the current field. They are not sticky. The angle is
not valid when MAGL or MAGH is set or MD is clear. See page 52.
