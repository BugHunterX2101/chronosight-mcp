# 32 CONF2 other fields (DIR, HYST, WD)

## 32.1 DIR (CONF2 bit 3)

  DIR = 0   angle increases for clockwise rotation, seen from the top
  DIR = 1   angle increases for counter-clockwise rotation

DIR is volatile. After a reset it returns to 0. A host that sets DIR = 1
must set it again after every reset (page 15, page 58).

## 32.2 HYST[1:0] (CONF2 bits 5..4)

  HYST    Hysteresis on ANGLE
  0       none
  1       1 LSB
  2       2 LSB
  3       3 LSB

Hysteresis suppresses toggling of the last bits when the shaft is at rest.
It is applied after FILT and does not reduce noise in a moving shaft.

Important: hysteresis is not a noise filter for servo loops. With HYST > 0
the output moves in steps, which a derivative term turns into spikes. Use
FILT instead (page 49). Hysteresis does not affect RAW.

## 32.3 WD (CONF2 bit 6)

  WD = 0   watchdog disabled (default)
  WD = 1   watchdog enabled; the device resets itself if the internal
           oscillator stalls for more than 1 ms (page 54)

Because the watchdog reset is also a reset, it clears CONF2, including WD
itself. The host sees STATUS.RST = 1 after a watchdog reset (page 33).

## 32.4 Example values

  Purpose                                   CONF2 value
  Defaults (after any reset)                0x00
  FILT = 3, everything else default         0x03
  FILT = 3, DIR = 1                         0x0B
  FILT = 5, HYST = 1, WD = 1                0x55
