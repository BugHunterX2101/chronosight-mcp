# 34 ANGLE and RAW output registers

## 34.1 ANGLE (0x0C-0x0D, R)

  Register   Bits   Field          Description
  ANGLE_H    7:6    -              Read as 0
  ANGLE_H    5:0    ANGLE[13:8]    Scaled angle, high bits
  ANGLE_L    7:0    ANGLE[7:0]     Scaled angle, low bits

ANGLE is the filtered angle after ZPOS, MPOS, DIR and HYST.

## 34.2 RAW (0x0E-0x0F, R)

  Register   Bits   Field          Description
  RAW_H      7:6    -              Read as 0
  RAW_H      5:0    RAW[13:8]      Raw angle, high bits
  RAW_L      7:0    RAW[7:0]       Raw angle, low bits

RAW is the filtered angle before ZPOS, MPOS, DIR and HYST. FILT does act on
RAW: RAW is taken after the filter (page 6).

## 34.3 Data consistency

A multi-byte read latches the high and low bytes together at the start of
the read, so ANGLE_H and ANGLE_L (or RAW_H and RAW_L) always belong to the
same sample when they are read in one transaction. Two separate single-byte
reads can combine bytes from different samples.

## 34.4 Converting to radians

    angle_rad = code x 2 x pi / 16384
    angle_deg = code x 360 / 16384

One code is 383.5 µrad = 0.02197°.

## 34.5 Unwrapping

The output wraps from 16383 to 0. For a joint that moves less than half a
revolution between two reads, unwrap by adding or subtracting 16384 when
the difference between consecutive reads exceeds 8192 in magnitude.
