# 60 Glossary and licence

## 60.1 Glossary

  AGC         Automatic gain control of the magnetic front end (page 35)
  BOR         Brown-out reset: reset caused by VDD falling below VBOR
  CONF2       Volatile configuration register 0x08 (FILT, DIR, HYST, WD)
  CORDIC      Algorithm that computes the angle from the sine and cosine
  FILT        CONF2 bits 2..0: output noise filter setting (page 31)
  LSB         One count of the 14-bit angle, 360 / 16384 = 0.022°
  OTP         One-time programmable memory (page 36)
  POR         Power-on reset
  RST         STATUS bit 0: a reset occurred since the last STATUS read
  tau         Time constant of the FILT filter, 2^n / 8000 s
  VBOR        Brown-out reset threshold, 2.6 V typical
  VPOR        Power-on reset threshold, 2.8 V typical

## 60.2 Fictional device notice

The EncoderX-14 is a fictional device. This manual was written for the
ChronoSight project as a test corpus. Any similarity to a real product is
unintended. Do not use the values in this manual to design real hardware.
