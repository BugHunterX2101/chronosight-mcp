# 40 Burst read of STATUS and ANGLE

## 40.1 The recommended per-cycle read

A 3-byte burst read starting at STATUS returns the status and the angle in
one transaction:

  S | 0x98 | A | 0x0B | A | Sr | 0x99 | A | STATUS | A | ANGLE_H | A |
  ANGLE_L | NA | P

  Byte 0   STATUS  (RST, MAGL, MAGH, MD, OVF)
  Byte 1   ANGLE_H (bits 13..8)
  Byte 2   ANGLE_L (bits 7..0)

STATUS and ANGLE are latched together. The read clears STATUS.RST (page 33).

## 40.2 Why read STATUS every cycle

  - RST tells the host that CONF2 has been cleared, so the filter is off and
    DIR is 0 (page 58). The host must rewrite CONF2 in the same step.
  - MAGL, MAGH and MD tell the host whether the angle is valid (page 52).

## 40.3 Host pseudocode

    every control period (1 ms):
        status, angle = burst_read(0x0B, 3)
        if status & 0x01:                 # STATUS.RST
            write(0x08, CONF2_VALUE)      # restore FILT, DIR, HYST, WD
        if (status & 0x06) or not (status & 0x08):
            hold_last_command()           # angle not valid (page 52)
        else:
            run_controller(angle)

## 40.4 Burst read of 4 bytes or more

A burst read that continues past ANGLE_L reads RAW_H and RAW_L (0x0E-0x0F).
A burst read past 0x0F wraps incorrectly on all silicon revisions; see
errata E-4 on page 59.
