# 58 Errata E-3: CONF2 is cleared by every reset

## 58.1 Description

Every reset clears CONF2 to 0x00. This includes power-on, brown-out,
watchdog and soft reset (page 11). After the reset:

  - FILT = 0: the noise filter is off (12 LSB RMS output noise).
  - DIR = 0: the angle increases for clockwise rotation.
  - HYST = 0 and WD = 0.

Revision 1.0 of this manual stated that brown-out resets preserve CONF2.
That statement was wrong. There is no reset source that preserves CONF2.

## 58.2 Affected silicon

All revisions (0xA1 and 0xA2). This behaviour will not change.

## 58.3 Effect on applications

A brown-out reset is silent (page 11, page 53). A host that writes CONF2
only at start-up runs with FILT = 0 after the first brown-out. In a servo
loop:

  - Angle noise rises from 3.10 LSB RMS (FILT = 3) to 12.0 LSB RMS.
  - Velocity noise at 1 kHz rises from 78 °/s RMS to 373 °/s RMS
    (table 48-1).
  - Motor current noise, tracking error and audible noise increase.
  - If DIR = 1 was used, the feedback sign reverses.

The configuration read back after the original write was correct, so a
start-up self-test does not catch this failure.

## 58.4 Workaround

Read STATUS on every control cycle and rewrite CONF2 in the same cycle
whenever STATUS.RST = 1:

    status, angle = burst_read(0x0B, 3)
    if status & 0x01:                 # STATUS.RST, sticky, cleared by read
        write(0x08, CONF2_VALUE)      # restore FILT (and DIR, HYST, WD)

The rewrite must happen in the same cycle because the read that reports
RST also clears it (page 33). See page 45 for the full initialisation.

## 58.5 Verification

Force a soft reset (write 0xA5 to CMD) while the loop is running. Within
one control cycle CONF2 must read back as CONF2_VALUE.
