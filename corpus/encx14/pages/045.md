# 45 Recommended initialisation

## 45.1 Start-up

    def encoder_init():
        wait_ms(2)
        assert read(0x00) == 0x14            # CHIP_ID
        read(0x0B)                           # clear RST from power-up
        write(0x08, CONF2_VALUE)             # e.g. 0x03 for FILT = 3
        assert read(0x08) == CONF2_VALUE

## 45.2 Every control cycle: rewrite CONF2 after a reset

    def control_step():
        status, angle = burst_read(0x0B, 3)  # page 40
        if status & STATUS_RST:              # bit 0, sticky, cleared by read
            write(0x08, CONF2_VALUE)         # the reset cleared CONF2
            log_event("encoder reset")
        ...

The rewrite costs one 3-byte write transaction, about 70 µs at 400 kHz.
Because RST is cleared by the read that reports it, the rewrite must happen
in the same control step. A host that only checks RST at start-up will run
with FILT = 0 after the first brown-out.

## 45.3 Value to write

Choose FILT using page 49. For a robot joint with a 1 kHz loop and a
crossover between 3 and 10 Hz, FILT = 3 is a good starting point
(CONF2 = 0x03). Handle direction in host software if possible, so that a
missed rewrite cannot reverse the feedback sign.

## 45.4 Firmware review checklist

  [ ] CONF2 is written at start-up, after CHIP_ID is confirmed.
  [ ] STATUS is read on every control cycle (burst read from 0x0B).
  [ ] CONF2 is rewritten in the same cycle whenever STATUS.RST = 1.
  [ ] Encoder resets are counted and logged.
  [ ] The angle is not used while MAGL or MAGH is set or MD is clear.
  [ ] No burst read runs past 0x0F (errata E-4).
