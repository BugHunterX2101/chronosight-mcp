# 59 Errata E-4 and E-5

## 59.1 E-4: burst read wraps 0x0F -> 0x10

Description: the register pointer was designed to wrap from 0x0F (RAW_L)
back to 0x0B (STATUS). On all silicon it continues to 0x10 instead. The
byte read from 0x10 is undefined (page 41).

Affected silicon: 0xA1 and 0xA2.

Effect: a host that reads more than 5 bytes from 0x0B, expecting STATUS
again at byte 6, reads an undefined value instead. If that value has bit 0
set, the host may treat it as a reset; if it has bit 0 clear, a real reset
reported in a later read can be missed by code that only checks byte 6.

Workaround: keep burst reads within 0x0B-0x0F. Start every read
transaction with an explicit register address. The recommended read is
the 3-byte burst from 0x0B (page 40).

## 59.2 E-5: low-power entry delay

Description: on rev 0xA1, after CONF1.PM is changed from 0 to 1 or 2, the
device takes up to 20 ms instead of the specified 1 ms to enter the low-
power mode. During that time the current consumption is that of active
mode.

Affected silicon: 0xA1. Corrected in 0xA2.

Effect: battery-powered designs that switch to low power for short idle
periods save less energy than expected. Servo loops, which should use
PM = 0 (page 29), are not affected.

Workaround: allow 20 ms for low-power entry on 0xA1, or use rev 0xA2.
