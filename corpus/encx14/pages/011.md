# 11 Supply, power-on reset and brown-out reset

## 11.1 Reset sources

The device has four reset sources. All four drive the same internal reset
line and have the same effect on the registers.

  Source        Trigger                                     Page
  Power-on      VDD rises through VPOR = 2.8 V              11
  Brown-out     VDD falls below VBOR = 2.6 V for > 2 µs     11
  Watchdog      internal oscillator stalls for > 1 ms       54
  Soft reset    host writes 0xA5 to CMD (0x30)              36

## 11.2 Effect of a reset

On every reset:

  - CONF2 returns to 0x00. FILT = 0 (filter off), DIR = 0, HYST = 0, WD = 0.
  - STATUS is cleared and then STATUS.RST (bit 0) is set.
  - ZPOS, MPOS and CONF1 are reloaded from OTP.
  - The I²C interface is idle and ready 1.5 ms after the reset ends.
  - The first valid angle is available 2.0 ms after the reset ends.

## 11.3 Thresholds

Table 11-1. Power-on and brown-out thresholds.

  Parameter                      Symbol   Min    Typ    Max    Unit
  Power-on reset threshold       VPOR     2.70   2.80   2.90   V
  Brown-out reset threshold      VBOR     2.50   2.60   2.70   V
  Brown-out filter time          tBOR     1      2      4      µs
  Reset to I²C ready             tRDY            1.5    2.0    ms
  Reset to first valid angle     tVAL            2.0    2.5    ms

## 11.4 Important: brown-out resets are silent

A brown-out reset can be shorter than one host control period. The host
does not see a bus error and the angle keeps arriving after 2 ms. The only
evidence is STATUS.RST, which stays set until the host reads STATUS (page
33). The configuration written by the host at start-up is lost: CONF2 is
back to 0x00 and the noise filter is off. Errata E-3 on page 58 describes
the consequences and the required workaround.
