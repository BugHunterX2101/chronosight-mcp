# 22 Alignment error and its effect on accuracy

## 22.1 Error budget example

For a robot elbow joint with the reference magnet at a 1.5 mm gap:

  Source                               Peak error
  Lateral displacement 0.25 mm         0.28°
  Tilt 1°                              0.05°
  Integral non-linearity (page 27)     0.10°
  Stray field from motor (5 mT)        0.15°
  Total (root sum of squares)          0.35°

At the end of a 300 mm forearm, 0.35° corresponds to 1.8 mm. This is a slow
error that depends on the joint angle. It does not cause oscillation.

## 22.2 Noise is a separate budget

Output noise is random and broadband (page 26). With FILT = 0 the noise is
12 LSB RMS = 0.26° RMS. At the end of a 300 mm forearm this is 1.4 mm RMS of
apparent position noise. A position loop with a high proportional gain and a
derivative term turns this noise into motor torque, which can be seen as
vibration of the arm. The noise budget is set by FILT, not by alignment.

## 22.3 Calibration

Alignment errors can be calibrated out with a look-up table in the host
firmware. Noise cannot be calibrated out; it can only be filtered (page 31,
page 49).

## 22.4 Summary

  Error type          Varies with           Reduced by
  Alignment           shaft angle           mechanical fix, calibration
  Stray field         motor current         shielding, distance
  Non-linearity       shaft angle           calibration
  Output noise        nothing (random)      FILT[2:0], host filtering
