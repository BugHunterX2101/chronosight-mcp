# 25 ADC and CORDIC angle computation

## 25.1 ADC

Two sigma-delta ADCs convert Bx and By simultaneously at 8 kHz. Each
conversion has 12 effective bits. Simultaneous sampling avoids an angle
error that would otherwise grow with rotational speed.

## 25.2 CORDIC

The CORDIC engine computes the angle atan2(By, Bx) in 16 iterations and
rounds the result to 14 bits. The CORDIC result is available 60 µs after
the start of the ADC sample (page 23).

## 25.3 Output resolution versus noise

The output has 14 bits (0.022° per LSB). With FILT = 0 the output noise is
12 LSB RMS, so only about 7.7 bits are noise-free in a single read. The
FILT filter trades bandwidth for noise (page 31):

  FILT     Noise (LSB RMS)   Noise-free bits (approx.)
  0        12.0              7.7
  3        3.10              9.6
  5        1.51              10.7
  7        0.75              11.7

Noise-free bits are computed as 14 - log2(6.6 x noise), where 6.6 x RMS is
the peak-to-peak noise for a Gaussian distribution at 99.9 % coverage.

## 25.4 Linearity

The CORDIC engine is exact to within 0.25 LSB. Non-linearity is dominated
by magnetic effects (page 27).

## 25.5 Output data rate

ANGLE and RAW are updated every 125 µs (8 kHz). A host that reads faster
than 8 kHz receives repeated values.
