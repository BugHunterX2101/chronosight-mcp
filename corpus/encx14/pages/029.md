# 29 CHIP_ID, REV and CONF1

## 29.1 CHIP_ID (0x00, R)

  Bits   Field      Value
  7:0    CHIP_ID    0x14

Read CHIP_ID at start-up to confirm that the device answers on the expected
address. A value other than 0x14 means a wrong address, a bus fault, or a
different device.

## 29.2 REV (0x01, R)

  Bits   Field      Value
  7:4    MAJOR      0xA
  3:0    MINOR      0x1 (first silicon) or 0x2 (E-1, E-2 corrected)

## 29.3 CONF1 (0x02, RW, OTP shadow)

  Bits   Field      Default   Description
  7:6    -          0         Reserved, write 0
  5:4    PM[1:0]    0         Power mode: 0 = active, 1 = low power 1,
                              2 = low power 2, 3 = reserved
  3      ADCSLOW    0         1 = halve the ADC rate to 4 kHz (saves 1 mA,
                              doubles FILT time constants)
  2:0    -          0         Reserved, write 0

CONF1 is reloaded from OTP after every reset. If CONF1 has not been burnt,
its OTP value is 0x00.

## 29.4 Low-power modes

  PM    Sampling            Current    Note
  0     continuous 8 kHz    6.5 mA     Use for servo loops
  1     8 kHz, 50 % duty    3.4 mA     Adds 125 µs of jitter
  2     8 kHz, 12.5 % duty  1.2 mA     Not for servo loops

Entering low-power mode takes longer than specified on rev 0xA1 silicon;
see errata E-5 on page 59.
