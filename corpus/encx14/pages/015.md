## 15.1 Sensor centre

The centre of the Hall array is in the centre of the package body, within
±0.1 mm. Use the package outline, not the pin row, to place the magnet axis
(page 21).

## 15.2 Direction of rotation

Looking at the top of the package, with DIR = 0 (default), the angle code
increases when the magnet rotates clockwise. Setting CONF2.DIR = 1 reverses
the direction (page 32).

Important: because DIR lives in CONF2, a brown-out reset also returns DIR to
0 (page 58). A host that relies on DIR = 1 will see the direction reverse
after a brown-out. In a position loop this turns negative feedback into
positive feedback. Prefer to handle direction in host software, or rewrite
CONF2 after every reset (page 45).
