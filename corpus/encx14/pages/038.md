# 38 Write transaction

## 38.1 Sequence

  S | 0x98 (0x4C + W) | A | ptr | A | data0 | A | data1 | A | ... | P

Each data byte is written to the register at the pointer, and the pointer
is incremented after every byte.

## 38.2 Example: enable the filter

Set FILT = 3 (CONF2 = 0x03):

  S | 0x98 | A | 0x08 | A | 0x03 | A | P

## 38.3 Example: set ZPOS to 0x1234

  S | 0x98 | A | 0x03 | A | 0x12 | A | 0x34 | A | P

## 38.4 Writes to read-only and reserved registers

Writes to read-only and reserved registers are acknowledged and ignored.
The pointer is still incremented.

## 38.5 Write confirmation

The device does not report whether a write took effect. To confirm a
configuration write, read the register back. A host that writes CONF2 and
immediately reads it back can still lose the value later through a reset;
read-back confirms the write, not that the value will stay (page 58).

## 38.6 Timing between writes

There is no minimum time between write transactions, except after a soft
reset (2 ms) and during an OTP burn (10 ms).
