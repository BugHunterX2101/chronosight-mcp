# 4 Safety and usage notes

The EncoderX-14 is a fictional component described for software and
documentation research. The notes below are written as a real manual would
write them, so that the document reads realistically.

## 4.1 Intended use

The EncoderX-14 measures the absolute angle of a diametrically magnetised
magnet that rotates above the package. Typical uses are motor commutation,
robot joint position feedback, knobs and gimbals.

The device is not rated for safety functions. A safety-rated joint must use
an independent second channel and a diagnostic coverage analysis that does
not rely on this device alone.

## 4.2 Behaviour after a reset

Important: the device has several reset sources (power-on, brown-out,
watchdog and soft reset, see page 11 and page 51). After any reset the
volatile configuration returns to its default values. A host that writes its
configuration only once at start-up will silently lose that configuration
after the first brown-out. See errata E-3 on page 58 and the recommended
initialisation on page 45.

## 4.3 Strong magnetic fields

Fields above 120 mT do not damage the device but drive the Hall front end
into saturation. The MAGH flag (page 33) is set and the angle output is not
valid while MAGH is set.

## 4.4 Electrostatic discharge

The device is ESD sensitive. Handle it at an ESD-protected workstation.
ESD ratings are on page 56.

## 4.5 Motor drives

Place the encoder at least 15 mm away from motor windings and high-current
traces, or shield it. Stray fields from a motor add a slowly varying angle
error that the FILT filter cannot remove, because the filter only acts on
broadband noise above its corner frequency (page 31).
