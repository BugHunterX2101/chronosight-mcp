# EncoderX-14 Reference Manual

14-bit contactless magnetic absolute angle encoder with I²C interface

Document ENCX14-RM, revision 1.2

NOTICE: THE ENCODERX-14 IS A FICTIONAL COMPONENT.

This manual was written for the ChronoSight project as an original
reference document. It describes an imaginary part. No real product, vendor
or datasheet is reproduced or paraphrased here. Any resemblance of register
names, values or behaviour to a real device is coincidental. Do not use this
document to design real hardware.
