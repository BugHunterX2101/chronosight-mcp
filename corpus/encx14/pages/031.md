# 31 CONF2 and the FILT[2:0] filter

## 31.1 CONF2 (0x08, RW, volatile)

Table 31-1. CONF2 bit fields.

  Bits   Field       Default   Description
  7      -           0         Reserved, write 0
  6      WD          0         Watchdog enable (page 32, page 54)
  5:4    HYST[1:0]   0         Output hysteresis, 0 to 3 LSB (page 32)
  3      DIR         0         Direction: 0 = clockwise increases (page 32)
  2:0    FILT[2:0]   0         Output noise filter setting n, 0 = off

CONF2 has no OTP shadow. Its value after any reset is 0x00, so FILT = 0 and
the filter is off. This includes brown-out resets (errata E-3, page 58).

## 31.2 The FILT filter

FILT selects a first-order IIR low-pass filter that runs on the angle at the
8 kHz internal sample rate, before the RAW and ANGLE registers:

    y[k] = y[k-1] + alpha x (x[k] - y[k-1]),   alpha = 2^-n,  n = FILT[2:0]

With n = 0 the filter is bypassed. The time constant is tau = 2^n / 8000 s
and the -3 dB bandwidth is approximately 1 / (2 x pi x tau). For white input
noise the output noise is multiplied by sqrt(alpha / (2 - alpha)).

Table 31-2. Output noise and bandwidth versus FILT (60 mT, 25 °C).

  FILT n   alpha    tau        Noise (LSB RMS)   Noise (° RMS)   Approx. BW
  0        1        off        12.0              0.264           -
  1        1/2      0.25 ms    6.93              0.152           637 Hz
  2        1/4      0.5 ms     4.54              0.100           318 Hz
  3        1/8      1 ms       3.10              0.068           159 Hz
  4        1/16     2 ms       2.155             0.047           79.6 Hz
  5        1/32     4 ms       1.51              0.033           39.8 Hz
  6        1/64     8 ms       1.06              0.023           19.9 Hz
  7        1/128    16 ms      0.75              0.016           9.9 Hz

## 31.3 Writing FILT

To set FILT = 3 with the other CONF2 fields at their defaults, write 0x03 to
address 0x08. To change FILT without changing other fields, read CONF2,
clear bits 2..0, OR in the new value and write it back.

## 31.4 Important

  - FILT = 0 after every reset. A host that needs the filter must write
    CONF2 at start-up and again after every reset (page 45, page 58).
  - FILT adds phase lag (table 12-1). Do not choose a time constant that is
    large compared with the period of the fastest motion you control.
  - If ADCSLOW = 1 (page 29), the filter runs at 4 kHz and every tau in
    table 31-2 doubles.
