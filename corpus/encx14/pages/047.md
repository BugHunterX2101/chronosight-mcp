# 47 Application: servo loops

## 47.1 Typical joint loop

A typical robot joint runs a cascaded loop on a microcontroller:

  - Position loop: 1 kHz, input = encoder angle, output = velocity command.
  - Velocity loop: 1 kHz, input = velocity estimate from the encoder angle,
    output = current command.
  - Current loop: 10 kHz to 20 kHz in the motor driver.

The EncoderX-14 provides the angle for the outer two loops. The host reads
the angle once per control period with a 3-byte burst read from 0x0B
(page 40), which also returns STATUS.

## 47.2 What the encoder adds to the loop

  - Delay: the read latency of 2 ms (page 12) for a host that polls once
    per 1 ms period and uses the result in the following period.
  - Filter lag: the FILT setting adds the lag of a first-order filter with
    time constant tau = 2^n / 8000 s (page 31).
  - Noise: 12 LSB RMS at FILT = 0, less with FILT > 0 (table 31-2).
  - Quantisation: 1 LSB = 360 / 16384 = 0.022°.

## 47.3 Loop design summary

For a joint with a crossover between 3 Hz and 10 Hz:

  - Delay and filter lag together must stay small compared with the phase
    margin. Table 12-1 gives the total lag at 4 Hz.
  - Noise must be small enough that the derivative path does not drive the
    motor with noise (page 48).
  - FILT = 3 balances these two needs (page 49).
