# 37 I²C protocol overview

## 37.1 Bus parameters

  Address       0x4C (ADDR = GND) or 0x4D (ADDR = VDD), 7-bit
  Speeds        100 kHz, 400 kHz, 1 MHz
  Byte order    Most significant byte first
  Pointer       8-bit register pointer, auto-increment on read and write

## 37.2 Transactions

  Transaction       Sequence
  Write register    S, addr+W, ptr, data..., P
  Read register     S, addr+W, ptr, Sr, addr+R, data..., P
  Read current      S, addr+R, data..., P    (uses the last pointer)

  S = START, Sr = repeated START, P = STOP.

## 37.3 Pointer behaviour

The register pointer persists between transactions. After a read of N
bytes starting at pointer p, the pointer is p + N (with the wrap behaviour
described on page 41). A "read current" transaction therefore continues
where the last read ended, which is rarely what a control loop wants. Always
set the pointer explicitly.

## 37.4 Reset and the bus

During a reset the device releases SDA and does not respond to its address.
A transaction that starts during the 1.5 ms after a reset is NACKed. After
a brown-out the pointer is reset to 0x00.

## 37.5 Typical control-loop traffic

One 3-byte burst read from 0x0B per control period (page 40). Configuration
writes only at start-up and after STATUS.RST (page 45).
