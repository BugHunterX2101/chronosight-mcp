# 43 Power-up sequence

## 43.1 Sequence

  t = 0         VDD rises through VPOR (2.8 V). Power-on reset.
  t = 1.5 ms    I²C interface ready. STATUS = 0x01 (RST) plus field flags.
  t = 2.0 ms    First valid angle. MD = 1 if a magnet is present.
  t = 12 ms     AGC settled (10 ms time constant).

## 43.2 What the host should do

  1. Wait at least 2 ms after VDD is stable.
  2. Read CHIP_ID (expect 0x14) and REV.
  3. Read STATUS. Expect RST = 1 on the first read after power-up.
  4. Write CONF2 with the required FILT, DIR, HYST and WD values.
  5. Read CONF2 back and compare.
  6. Wait 12 ms for the AGC to settle before closing the control loop.
  7. Start the control loop with the per-cycle burst read (page 40).

## 43.3 Slow supply ramps

If VDD rises slowly through VPOR and then dips (for example when a motor
driver on the same rail is enabled), the device can see a power-on reset
followed by a brown-out reset. The second reset clears the CONF2 value the
host has just written. This is why step 7 must include the STATUS.RST check
on every cycle, not only at start-up.

## 43.4 Host reset without encoder reset

If the host resets but the encoder does not, STATUS.RST is 0 on the first
read and CONF2 still holds the old value. The host should write CONF2
anyway at start-up so that its configuration is known.
