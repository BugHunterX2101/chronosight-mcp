# 50 Velocity estimation

## 50.1 No velocity output

The device has no velocity register. The host estimates velocity from
successive angle samples.

## 50.2 Unwrapping

The angle wraps from 16383 to 0. Before differencing, unwrap:

    d = angle[k] - angle[k-1]
    if d > 8192:   d -= 16384
    if d < -8192:  d += 16384
    velocity = d x (2 x pi / 16384) / T      # rad/s, T = loop period

This is valid while the joint turns less than half a revolution per loop
period (30000 rpm at 1 kHz).

## 50.3 Estimators

  Estimator              Noise          Lag         Note
  One-step difference    highest        T / 2       Use with FILT >= 3
  N-step difference      / N            N x T / 2   Simple, good at low speed
  Tracking observer      tunable        tunable     Best, needs tuning

## 50.4 Interaction with FILT

FILT filters the angle before the host sees it, so it also filters every
velocity estimator that uses the angle. If CONF2 is cleared by a reset,
FILT drops to 0 and the velocity noise rises by a factor of about 5 at
1 kHz (table 48-1) without any change in host code. The velocity estimate
is often the first signal where a lost CONF2 becomes visible in logs.

## 50.5 Direction

If the host relies on DIR = 1 (page 32), a reset returns DIR to 0 and the
sign of the velocity estimate reverses. Handle direction in host software
where possible (page 15).
