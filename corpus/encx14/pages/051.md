# 51 Diagnostics overview

## 51.1 What the device reports

  Signal        Where            Meaning                          Page
  RST           STATUS bit 0     A reset occurred (sticky)        33, 53
  MAGL          STATUS bit 1     Field too weak                   52
  MAGH          STATUS bit 2     Field too strong                 52
  MD            STATUS bit 3     Magnet detected                  52
  OVF           STATUS bit 4     CORDIC overflow (sticky)         52
  AGC           0x1A             Front-end gain                   35, 52
  MAG           0x1B-0x1C        Field magnitude                  35, 52
  NACK          I²C              Bus or device fault              54

## 51.2 Reset sources and their evidence

All four reset sources (power-on, brown-out, watchdog, soft reset, page 11)
have the same effect and the same evidence: STATUS.RST = 1 on the next
STATUS read. The device does not record which source caused the reset.
A host can narrow it down:

  - Soft reset: the host itself wrote 0xA5 to CMD.
  - Power-on: the host also restarted, or the encoder supply was switched.
  - Watchdog: only possible with CONF2.WD = 1 (page 54).
  - Brown-out: everything else. In a running joint this is the most common
    cause (page 53).

## 51.3 What the device does not report

  - It does not report that CONF2 has changed. The only evidence is RST.
  - It does not report excessive noise. Noise is a property of the FILT
    setting and the field, not a fault.
  - It does not report a stalled host or a missed read.
