# 44 Default register values

Table 44-1. Register values after any reset.

  Addr   Name       Value after reset         Source
  0x00   CHIP_ID    0x14                      fixed
  0x01   REV        0xA1 or 0xA2              fixed
  0x02   CONF1      OTP value (0x00 if blank) OTP shadow
  0x03   ZPOS_H     OTP value (0x00 if blank) OTP shadow
  0x04   ZPOS_L     OTP value (0x00 if blank) OTP shadow
  0x05   MPOS_H     OTP value (0x3F if blank) OTP shadow
  0x06   MPOS_L     OTP value (0xFF if blank) OTP shadow
  0x08   CONF2      0x00                      volatile
  0x0B   STATUS     0x01 plus field flags     volatile

## 44.1 CONF2 = 0x00 means

  FILT = 0   the noise filter is off; output noise 12 LSB RMS (table 31-2)
  DIR = 0    clockwise rotation increases the angle
  HYST = 0   no hysteresis
  WD = 0     watchdog off

## 44.2 "Reset" means every reset

The values in table 44-1 apply after a power-on reset, a brown-out reset, a
watchdog reset and a soft reset. There is no reset source that preserves
CONF2. Revision 1.0 of this manual implied that brown-out resets preserve
CONF2. That was wrong; see errata E-3 on page 58.

## 44.3 Practical consequence

Every configuration value that the application needs and that is not in OTP
must be written by the host after every reset. The host learns about resets
from STATUS.RST (page 33).
